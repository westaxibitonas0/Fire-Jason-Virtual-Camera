<h1>Fire Jason Virtual Camera version 1.1</h1>
FJVC is a standalone and user-friendly virtual camera interface built around UnityCapture virtual camera.
Usage is quite simple:
 1. Open the FireJ1.1.exe Program.
 2. Press button that says Set up / Remove Drivers. (You need administrator privileges to do this.)
 3. Once the terminal shows somthing along the lines of finished, you can proceed.
 4. Press Select Video File and select your video file.
 5. Once the file shows up in blue text,
 6. press the Run Virtual Camera button.
 7. The UnityCapture terminal will show you virtual camera details.
 8. When you are done with your work you can press stop virtual camera.
 9. Afterwards you can close the FJVC window - the driver removal will start automaticly.
 
 If you encounter a bug please report it. If the program missbehaves, please just open and close it.
